# Rounder

App to edit Windows screenshots of a single window. Despite the windows having
rounded corners in Windows 11, screenshots are still square, and keep the background.\
Use this application to remove it.

It does what it says on the tin, though the result isn't perfect; this programme is
still a work in progress.

## Usage

To open the application, execute
```
rounder
```

1. Click the "Open" button to select a picture.
2. Click "Shave off corners" to remove the corners.
3. Click "Save modified picture" and choose a filename for the new file. It will automatically receive
    the .png extension.
